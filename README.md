# WordDeck

เว็บฝึกคำศัพท์ภาษาอังกฤษรายวันสำหรับใช้เอง — PWA ติดตั้งเป็นแอปบนมือถือได้ ใช้งานออฟไลน์ได้

**เปิดใช้งาน:** https://panithanxd.github.io/WordDeck/

## ระบบทวนซ้ำ
**ตอบถูกครั้งเดียวยังไม่ผ่าน** — ทุกช่วงเรียนวนหลายรอบ (ค่าเริ่มต้น 2 รอบ ปรับได้ 1–3 รอบที่ปุ่ม ⚙ ตั้งเวลา) และแต่ละรอบถามคนละแบบ:

| รอบ | รูปแบบคำถาม |
|---|---|
| 1 | อังกฤษ → เลือกความหมาย |
| 2 | ความหมาย → เลือกคำอังกฤษ (กลับด้าน ต้องนึกคำเอง) |
| 3 | ฟังเสียง → เลือกคำ |

ในหน้าทบทวน รอบ 2 จะเห็นความหมายไทยก่อนแล้วต้องนึกคำอังกฤษเอง ส่วนช่วงฝึกใช้ประโยครอบ 2 จะเปลี่ยนไปใช้ตัวอย่างประโยคอีกอัน

**ตอบผิดเมื่อไหร่ก็วนกลับ:**
1. ตอบผิด → โชว์เฉลยเต็ม (ความหมาย + ตัวอย่างประโยค + เสียง) ให้ทวนก่อน
2. กด "เข้าใจแล้ว · ทวนอีกรอบ" → คำนั้นถูกดันกลับเข้าคิวของรอบนั้นอีก 3 คำข้างหน้า แล้วจะโผล่มาถามซ้ำ
3. ผิดครบ 3 ครั้งในรอบเดียว → พักไว้ แล้วไปอยู่ต้นคิวของปุ่มทวนซ้ำ

**ปุ่ม "🔁 ทวนซ้ำทั้งหมด" บนหน้าวันนี้** ทวนคำของวันนั้น **ทุกคำ** ไม่ใช่เฉพาะคำที่ตอบผิด — เรียนไป 5 คำก็ทวนครบ 5 คำ โดยเอาคำที่ยังไม่แม่นขึ้นต้นคิวให้ กดซ้ำได้ไม่จำกัดรอบ

ช่วง **คำใหม่ (06:15)** มี 2 เฟส: ดูคำ+ฟังเสียง+ตัวอย่างประโยคก่อน แล้วเช็คความจำครบทุกรอบทันทีในช่วงเดียวกัน ไม่ใช่เลื่อนผ่านแล้วจบ

กล่อง Leitner ขยับเมื่อผ่าน**รอบสุดท้าย**เท่านั้น และคะแนนมินิเทสต์นับเฉพาะข้อที่ตอบถูก**ตั้งแต่ครั้งแรกของรอบ 1**

## ฟีเจอร์
- **หน้าวันนี้** — ตารางเรียน 6 ช่วงต่อวัน (06:15 / 09:30 / 12:30 / 15:30 / 19:45 / 21:30) กดเริ่มได้ทีละช่วง นับวันต่อเนื่อง (streak) และปุ่มทวนซ้ำทั้งหมด
- **ท่องศัพท์** — flashcard ระบบ Leitner 5 กล่อง (ทบทวน 0/1/3/7/21 วัน) กด "ยังไม่ได้" แล้วการ์ดจะวนกลับมาในรอบเดียวกัน
- **ทดสอบ** — 4 รูปแบบ: อังกฤษ→ไทย, ไทย→อังกฤษ, ฟังเสียง→เลือกคำ, เติมคำในประโยค
- **ฝึกออกเสียง** — SpeechRecognition ให้คะแนนความใกล้เคียง
- **คลังคำศัพท์** — 300 คำ 5 หมวด + เพิ่มคำเองได้ + export/import JSON
- **สถิติ** — ปฏิทินรายเดือนติ๊กวันที่เทสต์ผ่าน, กราฟจำนวนคำในแต่ละกล่อง, 10 คำที่ผิดบ่อยสุด
- **แจ้งเตือน** — ผ่าน service worker (เด้งได้ตอนแอปอยู่เบื้องหลัง) + ดาวน์โหลดตารางเป็น `.ics` ไปใส่ Google Calendar

## เพิ่มคำศัพท์
แก้ `data/words.json` แล้ว push — โครงสร้างต่อคำ:
```json
{"w":"schedule","ipa":"/ˈskedʒ.uːl/","pos":"noun","th":"ตารางเวลา","cat":"Everyday",
 "ex":[["What's your schedule?","ตารางเวลาคุณเป็นอย่างไร"],["The meeting is on schedule.","การประชุมตรงตามกำหนด"]]}
```
`cat` ใช้ได้: Everyday / Work / Technical / Communication / Email (ใส่หมวดใหม่ก็ได้ แอปจะสร้างตัวเลือกให้เอง)

## โครงสร้างไฟล์
```
index.html        โครงหน้า 6 แท็บ
style.css         สไตล์ + dark mode
app.js            ตรรกะทั้งหมด
data/words.json   คลังคำ 300 คำ
manifest.json     PWA manifest
sw.js             service worker (cache-first + แจ้งเตือน)
icons/            ไอคอน 192/512 + maskable + badge
```

## รันในเครื่อง
```bash
python -m http.server 8080
# เปิด http://localhost:8080
```
Service worker ต้องรันผ่าน http/https (เปิดไฟล์ตรงๆ แบบ `file://` จะไม่ทำงาน)

## ข้อมูลผู้ใช้
ความคืบหน้า คำที่เพิ่มเอง และตารางเวลา เก็บใน `localStorage` ของเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์) — สำรองข้อมูลด้วยปุ่ม Export JSON ในหน้าคลังคำศัพท์

## การแจ้งเตือนบนมือถือ
เบราว์เซอร์แต่ละตัวรองรับไม่เท่ากัน แอปจะเลือกวิธีที่ดีที่สุดที่มีให้อัตโนมัติ:
1. **Notification Triggers** — ตั้งเวลาเด้งล่วงหน้าโดยไม่ต้องเปิดแอป (Chrome บางเวอร์ชัน)
2. **Periodic Background Sync** — ให้ service worker เช็กตารางเป็นระยะ (ต้องติดตั้งเป็นแอปก่อน)
3. **Timer ในหน้าเว็บ** — ทำงานตราบใดที่แอปยังเปิดอยู่ (fallback)
